# GitHub User Activity CLI

A lightweight backend CLI tool built with Node.js to fetch and display the recent activity of any GitHub user directly in your terminal using the GitHub REST API.

---

## 🚀 Features

* **Terminal Activity Stream:** Fetches recent public events (Pushes, Pull Requests, Issues, Stars) for any specified GitHub username.
* **Custom Output Formatting:** Parses raw JSON responses into clean, human-readable terminal output.
* **Robust Error Handling:** Handles non-existent users, empty activity logs, API rate limits, and network connection errors gracefully.
* **Zero Overhead:** Pure backend execution with minimal external dependencies.

---

## 🛠️ Tech Stack

* **Runtime:** Node.js
* **Language:** JavaScript / TypeScript
* **HTTP Client:** Native Fetch / Axios

---

## 📋 Prerequisites

* Node.js (`v18.x` or higher) installed on your system.
